# CJH AI 剪辑工作台

面向 Apple Silicon Mac 的本地 AI 辅助粗剪工作台。导入包含脚本和素材的文件夹，分析台词与画面，在达芬奇生成粗剪，再导出可编辑的剪映草稿，由剪辑师审片和精剪。

**当前是实验版本，剪辑准确性仍在完善。** 流程完成不等于剪辑结果符合脚本；台词选择、补画面和表情保留需要人工核对。

源码快照：2026-11-20，包含截至 2026-11-13 的工作流改动。程序内版本标识为 `0.1.5-beta.20261105`。本仓库提供源码，**不包含完整 Mac 安装包、Python 运行时、模型权重或演示素材**。

## 三步流程

1. **放入文件夹**：脚本与素材可以放在一起，通过本机路径、文件夹选择或拖动导入。支持从含文字的 DOCX、TXT、Markdown 自动整理台词和画面要求。浏览器导入复制到本机，不上传云端。
2. **开始达芬奇粗剪**：准备已安装的本地模型服务，转写素材，匹配剧本，检查切点并建立独立项目。项目按日期和素材来源自动命名。
3. **交接剪映**：导出人物主轨、独立音轨及通过核验的第二轨补画面，尝试启动剪映并打开对应草稿。剪辑师继续检查内容和调整节奏。

任务保存分析缓存、进度、耗时、剪辑依据与待复核项。相同素材与配置可以复用分析结果；编辑器写入结果不明确时会停止，避免重复创建。

## 剪辑规则

目前只有 **按剧本剪辑** 一个模式。旧版本保存的严格、平衡、保留反应档位统一映射到此模式。

- 从原脚本提取台词和画面要求，不要求剪辑师改成固定格式。未识别到明确台词时提示补充或重新选择脚本。
- 优先按脚本选择完整台词，去除可确认的重复、倒数、拍摄指令与无关内容。不能可靠确认说话人时采用保守处理。
- 在真实词时间边界上裁切；不把脚本文字当成已经听到的语音，也不均匀分词补造时间码。
- 切点前后多帧检查用于保留反应、笑声和互动；已排除的话语不能被后续延长重新带回。
- 明确要求的第二轨画面必须有内容与位置证据，找不到时报告缺失，不用无关补画面凑数。
- 默认 3 分钟为目标时长，台词和动作完整性优先；仍可能超时或需要手工修剪。

## 已知限制

| 部分 | 当前边界 |
| --- | --- |
| 按脚本选段 | 口音、转写错误、临场改词与重复拍摄可能造成漏选、误选或保留废话。 |
| 第二轨画面 | 检索分数仅用于提出候选；视觉核验和安全遮盖位置可能不足，实际测试出现过没有生成第二轨的情况。 |
| 声音处理 | 参考声纹匹配不等于角色理解或重叠人声分离；不能保证只去掉编导并完整保留其他人。 |
| 表情与笑点 | 切点抽样不能代替全片连续理解，可能漏掉短反应或误判动作。 |
| 剪映交接 | 草稿格式及辅助功能界面随版本变化；启动剪映成功不等于指定草稿已经进入编辑页。 |
| 包装 | 提供基础花字、画面放大及指定音效组件；日常自动粗剪默认不自动完成综艺包装或成片导出。 |

近期回归测试覆盖代码行为，不代表实拍准确率，也不能证明所有素材都能提效。需要结合剪辑师实际修正耗时判断。

## 本地组件

| 组件 | 用途 |
| --- | --- |
| faster-whisper | 素材语音转写。 |
| 3D-Speaker / CAM++ | 参考声纹匹配及匿名分段辅助。 |
| SenseVoice / sherpa-onnx | 转写交叉复核及声音事件线索。 |
| Ollama / Qwen3-VL | 画面理解、候选核验及切点多帧复核。 |
| Chinese-CLIP、MediaPipe | 画面候选检索及人脸动作辅助。 |
| Qwen3-VL-Embedding | 可选的视频分窗语义检索。 |
| Qwen3-ASR、Qwen3-ForcedAligner | 可选的独立听写及真实词时间对齐。 |
| PyAV、FFmpeg、Pillow、pyJianYingDraft | 媒体处理、抽帧与剪映草稿导出。 |

语义检索和精确对齐使用独立 MLX 环境，与主运行时隔离。模型需先下载到本机；运行任务时不自动切换到云端模型。参考声音及个人声纹样本不随仓库发布，私人固定样本准备入口已禁用。

## 开发运行

目标环境为 Apple Silicon Mac，Python 3.12；Swift 辅助程序的构建目标是 macOS 14。完整链路需要已安装达芬奇和剪映，达芬奇外部脚本接口可用，并完成需要的 macOS 权限设置。

在仓库根目录准备环境：

```sh
python3.12 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python -m pip install -r requirements-speaker.txt -r requirements-vision.txt
```

这些命令只安装 Python 依赖，**不会把模型、编辑器和原生辅助程序一并装好**。完整工作流需要本机 `.local/` 中对应的模型、Ollama 运行时及 3D-Speaker 代码，具体目录约定见 `backend/common.py`、`backend/model_startup.py` 和 `distribution/build.py`。

需要可选的语义检索和精确对齐时，另建环境：

```sh
python3.12 -m venv .semantic-venv
.semantic-venv/bin/python -m pip install -r requirements-semantic.txt
```

在本机 `.local/semantic-engines.json` 配置 `python`、`embeddingModel`、`asrModel`、`alignerModel` 的绝对路径，以及 `videoRetrieval`、`preciseAlignment` 布尔开关。模型参数必须指向已存在的本地目录，不是在线模型名称。不要把该文件提交到 Git。

主环境和需要的模型准备完成后可启动：

```sh
.venv/bin/python backend/server.py
```

浏览器打开 `http://127.0.0.1:8765/`。已有工作台运行时不要另起同端口服务。

## 目录与打包

- `dist/`：直接提供给本地浏览器的前端代码，需要随源码提交。
- `backend/`：分析、脚本整理、选段、检索、声音保护、切点复核及编辑器连接。
- `distribution/`：Mac 构建、安装、桌面启动器、迁移工具和隔离测试。
- `distribution/licenses/`：保留的第三方许可与模型说明。
- `.local/`：运行后生成的模型、任务、分析、日志与配置，不属于仓库内容。

`distribution/build.py` 和 `build_bundle_release.py` 面向已经准备好依赖和缓存的构建环境，不能仅凭一次克隆从零生成离线包。安装载荷与模型需单独准备。本仓库未提供已经签名公证的发行安装包，也不承诺跨版本免配置运行。

## 数据与许可

服务默认只监听本机回环地址，公开副本仅接受本机网页来源。请勿将其直接暴露到公网。素材在本机分析，但首次安装依赖、下载模型和第三方编辑器自身联网不属于离线推理流程。

仓库排除了素材、客户脚本、任务记录、参考声音、模型权重、访问凭据和旧 Git 历史；测试中的人物与项目标识已泛化。不要提交自己的 `.local/`、运行日志或完整安装载荷。
